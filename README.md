# NorthB&B — marketing site + host signup

A fast, accessible redesign of the public NorthB&B website (Montenegro private-stay
booking). Static HTML/CSS + a tiny vanilla JS layer, served by a **Cloudflare Worker**
that adds security headers and handles form submissions. The live booking engine and
guest/host accounts remain on the existing TechnoHeaven platform — this site is the
marketing front end and the new, simplified **host signup**, and it hands off to the
booking system for live availability.

## Stack & structure

- No framework, no runtime build on the client. `build.mjs` composes pages from
  `src/chrome.mjs` (shared head/header/footer/icons) + `src/pages/*.mjs` into `public/`,
  and generates `sitemap.xml`, `robots.txt`, and CSP hashes for inline JSON-LD.
- `src/worker.js` — Cloudflare Worker: strict security headers (CSP with per-page
  JSON-LD hashes, HSTS, X-Frame-Options, etc.), cache headers, and the form API.
- `public/` — the deployable static site (served by the Worker via the `ASSETS` binding).
- `make_map.mjs` — one-off generator for `src/mapdata.mjs` (coastline-based land and Lake Skadar for the host-flow map, from Natural Earth, public domain).
- `/api/geocode` — Worker proxy to Photon (OSM) for the host-flow place search; Montenegro only, cached, rate limited.
- `optimize_images.py` — Pillow pipeline: source photos → responsive WebP in `public/assets/img`.

## Local development

```bash
npm install
npm run build      # compose public/ (also run after editing anything in src/)
npm run dev        # build + wrangler dev  (http://127.0.0.1:8788)
npm run images     # re-run the image pipeline (needs Python + Pillow); sources in .raw-img/
node qa.mjs        # link/heading/meta/alt/placeholder sweep
```

CSS (`public/assets/css/styles.css`) and JS (`public/assets/js/main.js`) are edited
directly; everything else is generated by `build.mjs`.

## Forms & data

`/api/host-signup`, `/api/contact`, `/api/newsletter` are handled by the Worker:
input sanitised, rate-limited to 5/IP/hour via KV, leads written to KV (`lead:*`, kept
90 days) and — when configured — emailed. The host form is a 3-step flow with inline
validation and a success state; contact and newsletter post inline.

## Deploy (Cloudflare Workers)

```bash
# 1. one-time: create the KV namespace and paste the ids into wrangler.toml
wrangler kv namespace create NB_KV
wrangler kv namespace create NB_KV --preview

# 2. (optional) enable email notifications for new leads
wrangler secret put RESEND_API_KEY     # uses Resend; falls back to KV-only if unset

# 3. ship
npm run deploy
```

## Launch checklist — needs confirmation before go-live

- [ ] **KV ids** pasted into `wrangler.toml` (`REPLACE_WITH_*`).
- [ ] **Host photos bucket**: `wrangler r2 bucket create northbnb-host-photos`. Optional
      listing photos from `/host/start/` land in R2 under `host-leads/<leadId>/`. Without
      the bucket the form still works and the lead email notes the photos were not stored.
- [ ] **Lead email**: set `RESEND_API_KEY` (and verify the sending domain) so new host
      leads are emailed to `info@northbnb.com`. Until then, leads live in KV only.
- [ ] **Booking/login routing** (`SITE.bookingBase`, `SITE.loginUrl`, host-dashboard URL
      in `src/chrome.mjs`): confirm where the retained booking app lives once this site
      becomes the homepage (e.g. a subdomain) so "Log in" / "See available stays" point
      at it, not at the page being replaced.
- [ ] **Payoneer as a guest payment method** is shown as a host benefit now; before
      advertising it to *guests* at checkout, enable it in the TechnoHeaven checkout.
- [ ] **Destination photos**: the three thumbnails are low-res brand images (~275px).
      Swap in higher-resolution shots when available.
- [ ] **Stats**: the home stat band uses defensible figures. Add real numbers
      (years in business, guests hosted) for a stronger claim if you have them.
- [ ] **Legal review**: the privacy / cookie / terms pages are adapted from the
      CC0 General-Legal templates and customised for Trip North LLC / Montenegro
      (governing law set to Montenegro). Have counsel review before relying on them.
